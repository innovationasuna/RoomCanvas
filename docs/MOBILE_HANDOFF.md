# 手机体验与 App 导入

<a id="手机打开与-app-导入阶段-13"></a>

手机和电脑连接同一 Wi-Fi，就可以扫码查看电脑上摆好的房间。iPhone、iPad 和安卓手机都能使用浏览器。Android App 还能保存房间，下次离线打开。

<a id="使用方法"></a>

## 在电脑上分享

1. 启动电脑上的[网页编辑器](../web/README.md)，打开房间，确认或取消正在调整的物品。
2. 点右上角 **在手机中打开** → **生成二维码**，保持电脑服务运行。用手机相机扫码。
3. 手机选 **在浏览器中体验** 或 **在 Android App 中打开**。打开的是生成二维码时的布置。想分享新的布置，关闭电脑上的弹窗，重新打开并生成二维码。

也可以在同一弹窗中点 **下载房间 GLB**，把文件传到安卓手机，再在 App 点 **选择房间模型**。下载文件时无需开启局域网分享。

## 在手机上查看

| 打开方式 | 操作 |
| --- | --- |
| 浏览器总览 | 单指旋转，双指缩放。总览会隐藏顶面，近侧墙及其门窗、踢脚线随视角隐藏，方便看清室内。 |
| 浏览器漫游 | 点 **走进房间**，用方向键移动，滑动转向。墙面和顶面恢复显示。点 **视角复位** 回到起点，点 **退出漫游** 返回总览。 |
| Android App | 安装 RoomCanvas 0.2.0 或支持分享链接的更新版本。App 下载并校验模型，确认房间名和版本后点 **开始漫游**。成功导入后，可断网重新打开上次房间。升级时用原签名构建的 APK 覆盖安装，卸载会清除 App 私有目录里的离线房间。 |

iPhone / iPad 的 App 按钮显示为不可用，请选浏览器。安卓浏览器切换桌面模式仍可看到 App 入口。如果 App 没有打开，可留在分享页点浏览器按钮。旧版 App 可手动选择 GLB。[Android 安装、操作与构建](../android-app/README.md)

<a id="快照内容与边界"></a>

## 哪些布置会带到手机

- 已确认的位置、高度、大小、旋转和新增物品，连同贴图一起保存。已收纳的物品留在物品库。
- 模型包含完整墙壁和顶面。电脑上的临时隐藏、选中高亮和摆放预览只在编辑时显示。
- 手机网页沿用分享时的光照和调色。App 的渲染器可能呈现不同亮度。门窗等可开合部件按关闭状态导出，分享的房间用于静态查看和漫游。

## 打不开时

| 现象 | 可以怎么做 |
| --- | --- |
| 手机扫不到电脑 | 确认同一 Wi-Fi，避开隔离设备的访客网络，检查防火墙。多网卡或 VPN 下，在分享弹窗选择或填写手机可达的电脑局域网地址。 |
| 重启电脑服务后旧链接打不开 | 再生成一次二维码以开启分享端口。电脑地址与端口相同、旧分享仍有效时，可以继续使用原链接。 |
| 手机离开了局域网 | 回到同一 Wi-Fi 后重试原链接。只要电脑服务仍在运行、地址和端口未变、分享仍有效，就能继续打开。 |
| 分享链接已过期 | 分享默认保留 7 天。请在电脑上重新生成二维码。已导入 App 的房间仍可离线打开。 |
| App 提示下载或校验失败 | 确认电脑在线，检查手机空间后重试。失败时已成功导入的上一个房间仍然可用。 |
| 打包提示模型不受支持 | 含骨骼的模型暂时无法打包。单份局域网分享上限约为 536.9 MB。 |
