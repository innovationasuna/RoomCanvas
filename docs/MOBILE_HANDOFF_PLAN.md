首期范围：阶段 1～3。使用入口、安装包、协议及验证说明见 [手机打开与 App 导入](MOBILE_HANDOFF.md)。

## 1. 最终目标与范围

用户在电脑端完成房间布置后，点击“在手机中打开”，生成二维码或链接。手机打开后可选择“浏览器直接体验”或“在 Android App 中打开”，查看同一份房间布局并漫游。最终同时支持同一 Wi-Fi 和异地访问。

本轮产品边界：

- 手机端提供查看与漫游，房间编辑仍在电脑端完成。
- 分享包含已确认的家具位置、高度、朝向、新增物品与收纳结果；有未确认操作时，先提示确认或取消。
- 每次生成一个固定的布局版本；电脑后续编辑不会静默改变已分享版本。
- Android 支持浏览器与 App 两种方式；iPhone 通过浏览器体验。
- 首期使用同一 Wi-Fi，电脑服务须保持运行且手机能访问该电脑；扫码不等于已经解决网络连通性。
- 实时同步、多人编辑、手机端布置、iOS 原生 App 不列入阶段 1～5。

## 2. 实施前基础

| 项目 | 现有能力 | 需要补齐 |
| --- | --- | --- |
| 网页编辑器 | 调整家具、确认预览、导出布局 JSON | 导出带模型、贴图及当前布置的完整房间快照 |
| 网页服务 | 默认监听 `127.0.0.1`，供电脑本机访问 | 可控的局域网分享入口、手机可访问的地址与资源 |
| Android App | 通过系统文件选择器导入 `.glb`，复制到 App 内部并记住最近模型 | 接收分享链接、下载、校验并导入房间 |
| 手机网页 | 已有网页场景与漫游代码可复用 | 专用查看入口、触摸操作、真机兼容验证 |

现有布局 JSON 主要记录物体变换和可见性，不能单独替代完整房间文件。新增物品的模型与材质也需要进入分享快照。当前 App 的已安装版本是否与仓库一致，应在真机验收时确认。
