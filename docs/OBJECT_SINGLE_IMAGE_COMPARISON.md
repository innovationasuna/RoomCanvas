# 单图 TRELLIS.2 与 MV-SAM3D 烘焙结果对比

日期：2026-10-28。本轮按用户决定停止使用多图 TRELLIS，当前只保留单图 `trellis` 与 `mvsam3d` 新任务入口。MV 原有多图和补拍能力继续保留；本文比较的是两个物体各自同一张照片的单图结果。

## 比较对象

| 样本 | MV-SAM3D 烘焙 | TRELLIS.2 单图 |
| --- | --- | --- |
| 玩偶 | `20261028_pbr_plush_baked_a03` | `20261028_multiview_plush_single_a01` |
| 沙发 | `20261028_pbr_sofa_baked_a03` | `20261027_sofa_trial_a02` |

玩偶 TRELLIS 运行名虽包含 `multiview`，实际为该批次的 **single 基线，仅一张图**，不是多图结果。照片及确认蒙版指纹一致，均为 seed 42；分别保留模型自己的材质和网格预算。MV 为 Gaussian 颜色烘焙、2048 颜色贴图、roughness=1／metallic=0；TRELLIS 为基础色和逐区域金属度／粗糙度贴图、约 5 万面导出目标。

本轮复用已经完成的真实 GLB 渲染，没有重新生成模型。每对使用相同相机、灯光与归一高度，保留比例差异；排版时同一对使用共同裁切框。实际外观图、统一灰模图和移动光源图均由已有浏览器渲染重新排版，不使用生成式图片。

## 效果判断

| 项目 | MV-SAM3D 烘焙 | TRELLIS 单图 |
| --- | --- | --- |
| 玩偶形状 | 主体更平顺，五官与红心边界较规整 | 表面起伏更明显；这些凹凸不能直接算真实毛绒细节 |
| 沙发结构 | 保留分块坐垫及其边界 | 坐面被简化得较连续，部分结构与 MV 不同 |
| 颜色／图案 | 已比原顶点色有更多颜色表达，沙发金色抱枕更明显 | 本样本抱枕颜色、图案更鲜明，但不能据此认定所有外观更准确 |
| 灯光响应 | 可以受光；不同部位使用同一粗糙度和金属度 | 可以受光，具备逐区域不同的反射参数 |
| 固定明暗 | 颜色烘焙没有去光照，可能保留 Gaussian 外观中的固定明暗 | 材质也是模型估计，没有验证已正确分离实物材质与拍摄光照 |
| 当前取舍 | 这两组样本更适合优先保留其几何，再权衡颜色烘焙成本 | 适合需要直接获得较轻 PBR 资产、与场景复用模型的入口 |

统一灰模已经关闭颜色和材质贴图，可以看见两者几何差异；不能把更深的颜色阴影当作几何更好。当前只涉及两物体、各一张图和单 seed，没有扫描或材料真值，不给模型整体精度排名。

## 时间与展示成本

沙发完整重建为 MV 烘焙 **436.476 秒（约 7 分 16 秒）**、TRELLIS **218.201 秒（约 3 分 38 秒）**。MV 的烘焙适配阶段为 304.630 秒，主要耗在完整网格 UV。两次来自不同日期、GPU 和流程，不是同预算速度基准。

玩偶 TRELLIS 完整任务 **254.331 秒（约 4 分 14 秒）**；MV 最终烘焙从生成和 UV 快照恢复，外层 63 秒不包含这些前期处理，不能作完整重建时长比较。

| 项目 | MV 烘焙 | TRELLIS 单图 |
| --- | --- | --- |
| 玩偶三角面 | 915,988 | 46,898 |
| 沙发三角面 | 506,636 | 48,451 |
| 玩偶 GLB | 23.97 MB | 9.94 MB |
| 沙发 GLB | 15.31 MB | 9.58 MB |
| 单玩偶 GPU 帧时间 | 2.75 ms | 1.73 ms |
| 单沙发 GPU 帧时间 | 1.79 ms | 1.56 ms |
| 十沙发 GPU 帧时间 | 3.66 ms | 2.03 ms |
| 沙发几何＋纹理估算负载 | 37.12 MiB | 44.23 MiB |

GPU 数字来自本机 M5／Chrome、800×800、DPR1、缓存阴影的小场景，3 轮各 24 样本，取中位数；不是完整编辑器 FPS。十物体用普通网格副本，共享资源，资源表仍是一个独立资产。纹理按 RGBA8 加 mip 估算，合计不含驱动、阴影图或帧缓冲，不是进程总显存。TRELLIS 的轻几何有助于绘制，但两张贴图使内存负载未必更小；小的 GPU 时间差也会受系统波动影响。

完整计时口径、逐帧测量及限制见 [成本实测](OBJECT_RECONSTRUCTION_COST_COMPARISON.md)；烘焙实现、失败恢复、材质审计见 [MV 烘焙实验](OBJECT_MVSAM_PBR_EXPERIMENT.md)。

## 多图 TRELLIS 的处理

- `BACKENDS` 只允许 `mvsam3d`、`trellis` 创建新任务。环境变量或旧配置请求 `trellis_multi` 时明确报“已停用”，不静默退回单图。
- 单图适配器不再导入多图采样器或启动多图 worker；移除默认融合参数及网页多图说明。
- 旧结果仍按 `trellis_multi` 读取，保留 PBR 能力，并标记 `retired=true`；不会把旧多图结果冒充单图结果，也不会影响其下载、尺寸标定和展示。
- 历史模型、实验记录及独立采样代码保留回查，不再推荐为下一轮方向。此决定只更新当前工作区，正式服务未重启或部署。
