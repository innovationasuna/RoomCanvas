# 物体重建结果对比：MV-SAM3D 与 TRELLIS.2

2026-10-28 补充：[启用 MV-SAM3D 原生纹理烘焙后的对照](OBJECT_MVSAM_PBR_EXPERIMENT.md)。本文保留历史顶点色结果；新实验从同一次 MV 生成导出顶点色与烘焙 PBR，再与同图 TRELLIS 比较。

重建耗时、单物体／十物体 GPU 帧时间及贴图资源负载见 [成本对照](OBJECT_RECONSTRUCTION_COST_COMPARISON.md)，不要只用面数推断帧率或总显存。

日期：2026-10-27，分支 `feat/objects-trellis`。对比编辑器实际使用的完整 GLB，不比较 Gaussian；全部复用已有结果，本轮没有启动服务器 GPU 重建。TRELLIS 接入和此前验证见 [实验记录](OBJECT_TRELLIS_EXPERIMENT.md)。

## 判断

本批样本不足以支持把独立物体默认流程全面换成 TRELLIS.2。它在原生 PBR、抱枕／服装的颜色及纹理、输出网格面数方面有优势，但没有全面超过旧流程的形状还原。尤其沙发坐垫分块被丢失，Cody 底座文字变形明显。

| 比较项 | 实际观察 | 对当前选择的影响 |
| --- | --- | --- |
| 形状与结构 | 同图单张沙发中，旧模型保留分块坐垫，新模型生成较平的连续坐面。毛绒主体两边均可辨认，新模型表面起伏更多，但不能据此认定更接近实物 | 需要忠实还原时，继续保留 MV-SAM3D；不能只看新模型阴影更明显就判断形状更好 |
| 颜色与纹理 | 新沙发黑白格／金色抱枕、新 Cody 的红色服装更接近参考；旧模型部分颜色偏浅。新 GT3 的车灯和玻璃简化为较暗区域，蓝色也偏深 | TRELLIS 在部分外观细节有优势，但没有所有材质都更准确 |
| 文字 | Cody 旧结果的字样外观相对更接近参考，但也不完整；新结果变成难以辨认的曲线和块状。旧灰模也不能证明已正确恢复文字几何 | 两条路线都不能当作可靠文字重建方案；不能用“有贴图”替代字形检查 |
| 光照 | 旧默认 Basic 显示不响应灯移动，新原生 PBR 有响应；统一受光材质后旧网格同样有明暗与体积感 | 原先观感偏平，有一部分来自显示方式。缺少 PBR 参数与完全不能受光是两回事 |
| 网格规模 | 新结果约 4.7–4.85 万面，选中的旧结果约 40–92 万面；新结果面数少约 8–20 倍 | 可继续作为轻量 PBR 资产方向；没有测量加载时间或帧率，面数也不是质量评分 |

当前建议是保留两个后端：需要形状忠实度和多图输入时保留旧流程，TRELLIS 继续作为单图 PBR 资产入口验证；同时考虑对旧几何单独增强材质。这个判断针对以下结果，不是模型总体排名。

## 图的读法与复现

所有图均从真实 GLB 渲染，未使用生成式图片补画结果。每对使用相同正交相机、背景、灯光与曝光，各模型高度归一为 1，保留宽深比例差异；这不是实物尺寸标定。GT3 新模型仅绕竖轴旋转 180°，让两边车头朝向一致，没有修改网格形状。缺失法线按编辑器相同方式计算。

- `diffuse-comparison.png`：两侧使用同样的受光材质，粗糙度 0.75、金属度 0，分别保留旧顶点色和新基础色贴图；新金属度／粗糙度贴图在此对照中关闭，用于减少着色方式差异。
- `clay-comparison.png`：两侧使用同一个中灰材质，关闭顶点色和纹理，观察实际几何，而不是把颜色边界误当成结构。
- `appearance-comparison.png`：按当前产品默认显示，旧 Basic 顶点色、新原生 PBR；用于比较实际观感，不能单凭此图评价几何。
- `lighting-comparison.png`：相机固定、环境贴图关闭，灯从左移动到右。毛绒和 GT3 的旧默认显示两帧像素相同，新 PBR 两帧不同。该结果只验证显示路径，不证明估计出的材质正确；统一受光图也表明旧网格可以获得受光明暗。

本机图、下载模型、输入指纹、配置与渲染脚本在仓库外 `/tmp/roomcanvas-model-comparison-20261027/`，私人输入和生成资产不加入 Git。关键文件为 `comparison-config.json`、`comparison-summary.json`、`render_comparison.mjs`、`make_figures.py` 和 `renders/<物体>/report.json`。临时目录不会自动成为长期存档。

使用已存在的本机预览服务 `127.0.0.1:17880` 提供 Three.js；模型通过测试浏览器的临时路由从本机文件读取，没有扩大网页代理权限或改正式服务。运行 `node render_comparison.mjs` 后，再用含 Pillow／NumPy 的 Python 执行 `make_figures.py` 可重画。脚本路径与 Chrome／Playwright 路径按本机环境设置，跨电脑需调整。
