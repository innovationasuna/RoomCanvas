## 用户确认并已实现的交互

| 手型 | 行为 |
| --- | --- |
| 左手 1：食指伸直 | 选择移动物体 |
| 左手 2：食指、中指伸直 | 选择旋转物体 |
| 左手 3：食指、中指、无名指伸直 | 选择仅观察 |
| 右手拇指、食指捏合 | 移动/旋转模式操作物体；仅观察模式环绕视角 |
| 右手拇指、食指、中指合拢 | 仅观察模式平移视角 |

数字保持约 400ms 确认，空闲可直接稳定换另一数字，同一数字不反复触发。忙碌时忽略且不排队；忙碌或丢失后的恢复先回中性手型。右手切模式或换观察动作后，先完全松手再抓取。

观察动作开始时锁定，环绕过程中加入中指不会突然改平移；三指松开后两指仍闭合也不会立刻自动改环绕。释放首帧冻结相机，确认后固定；丢手保留最后有效视角；明确取消恢复抓取前视角。观察不修改物体布局、不触发碰撞或保存。

## 已完成验证

手势 74 项测试、类型检查、资源校验、构建通过；ViewForge 34 项测试、类型检查、构建通过。Chrome 合成摄像头/左右手关键点验证：数字模式选择与直接换数字、忙碌抑制、不重放、两指环绕、三指平移、动作锁定、释放不漂移、丢手保持、取消恢复、观察时布局不变且无校验请求。原移动、自由旋转、承托请求、全量替换、碰撞拒绝、异步取消和鼠标操作回归通过。

浏览器布局 API 使用内存夹具，没有保存服务器测试布局。原始识别资源在首版已通过真实 Worker + Chrome 合成摄像头加载检查；本阶段新手型的真人准确率、方向/增益和持续性能尚未验收。

## 下一步

1. **真人手型验收。** 体验左手 1/2/3、右手两指/三指闭合，记录误识别、过渡手型、手掌转动、遮挡、标签翻转和不同距离的表现。数字关节阈值与 400ms 确认时间按实际反馈单独调整。
2. **相机手感。** 确认环绕左右/上下方向、平移方向和速度，观察不同画布比例、相机距离和俯仰；需要时调整独立相机增益，保持物体尺寸与碰撞逻辑。
3. **真人回归。** 在真实房间和重建物体上试用移动、自由旋转、叠放、碰撞拒绝和轻量→全量替换，确认左手选模式不会打断右手操作，停止摄像头与丢手不误提交。
4. **持续性能。** 记录渲染/推理频率、延迟、冷启动和连续使用表现，特别观察 200ms/250ms 保护在较慢推理环境中的触发情况。
5. **按需细化反馈。** 根据真人反馈补充左手待确认/被忽略等提示；保持按钮作为备用输入。

本阶段的手势定义均已确认，无待确定的平移/环绕切换方式。缩放、高度、菜单、自然三维深度和历史撤销继续留在后续范围，新增手势需先约定。

最新调整：仅观察水平环绕已按用户要求反向，左手绿色指针和检测/确认进度已添加，自然收拢指判断已修正。后续真人验收重点确认绿色左手标记是否出现、数字识别与模式切换是否符合手型；遇到失败先根据右侧状态区分识别、右手捏合和场景忙碌。
