## 已确认的下一阶段交互

固定左手选模式、右手执行操作，不交换手的角色。

| 左手数字 | 模式 | 右手捏合操作 |
| --- | --- | --- |
| 1 | 移动物体 / `move` | 指向物体后捏合，沿地面或承托面移动，松手校验 |
| 2 | 旋转物体 / `rotate` | 指向物体后捏合，水平拖动自由旋转，松手校验 |
| 3 | 仅观察 / `view` | 捏合拖动调整相机视角，不移动或旋转布局中的物体 |

用户已确认观察模式同时需要 **视角平移和围绕目标环绕**。两者的手势切换方式留待后续约定，不能自行绑定另一数字、左右手组合或新增子模式并宣称完成。缩放视角、左手菜单、高度、物体缩放、自然三维深度与历史撤销不列入当前阶段。

观察模式先复用右手拇指/食指捏合，保持左手只选模式的分工。平移同步移动相机及观察目标；环绕调整 Babylon ArcRotateCamera 的 alpha/beta。两者均不能修改 Item 的 x/z/yaw/elevation/user_scale 或触发布局碰撞提交。

## 数字识别与防误触方案

首试建议：1 为食指伸直，2 为食指和中指伸直，3 为食指/中指/无名指伸直；其余手指收拢。具体手型作为待真人校准的建议，不把单纯任意伸出 N 根手指当作确认接口。若用户惯用另一种“3”，先约定模板再支持。

- 复用 MediaPipe 左手关键点和现有左右手置信度约束；识别代码放在手势仓库，ViewForge 不读取原始关键点。
- 独立提取数字特征并输出 1/2/3/unknown，使用指关节弯曲、指尖距离和掌尺度归一化，避免固定像素阈值；歧义、遮挡或低置信度输出 unknown。
- 数字稳定保持约 400ms 后触发一次，具体阈值集中配置并经真人调整。持续保持同一数字不反复发送；识别失效后恢复不能自动切换，先回到中性姿态再识别。
- 捏合、数字之间过渡、手指尚未稳定不能被当成新的数字。原识别捏合阈值和原演示行为保持既有约定。
- 物体预览及服务器校验期间忽略模式切换，不排队重放。操作结束后重新给出稳定数字才切换；切换后右手先松开再抓取。
- 仅在接入页消费数字指令，避免影响原演示的左手菜单和环绕功能。

## 协议与操作状态

数字选择优先复用已有 `mode` 消息（move/rotate/view），无需把左手关键点传给布局页。手势端仅在收到有效数字、场景 ready 且 idle 后发布切换请求；ViewForge 的 `state` 回执确认实际模式，按钮和提示以回执为准。

当前 `viewforge-gesture-v1` 只带右手输入。观察仍可复用右手帧，但不能把它直接当物体事务：需建立独立的相机操作会话。平移/环绕的动作选择字段及兼容策略在切换手势确定后再定，不能默认为已经对齐的接口。

保留 origin/source、会话、序号、sampleTime 和过期帧校验。右手开始释放首帧停止相机更新，确认释放固定最后有效视角；丢手立即冻结，长中断后清理相机会话，恢复必须松手重抓。观察中断固定最后有效视角，不生成物体布局提交。明确取消恢复抓取前视角，页面失焦/设备断开等终止条件与已有物体操作区分清楚。

鼠标相机操作与手势相机操作互斥；鼠标介入立即终止手势会话，恢复需松手。模式切换、观察开始及结束清除相机惯性，避免手已松开而视角继续移动。

## 实施顺序与文件范围

1. **数字识别。** 手势仓库新增独立数字模式识别模块及合成关键点夹具/测试，接入 runtime/main；先验证左手 1/2/3 的稳定确认、去抖、身份保护和中断恢复。
2. **切换现有模式。** 复用现有 mode/state 通信，在接入页完成左手选择 move/rotate/view。保持按钮可用，验证忙碌期忽略、恢复不重放、切换后松手重抓；无需更改重建与碰撞算法。
3. **确认观察操作契约。** 与用户约定平移/环绕切换手势、模式提示和必要的协议字段，随后再编写相机接口。
4. **相机操作。** ViewForge 的 layout.ts/独立相机控制模块处理 Babylon 相机；layout-gesture.ts/bridge 适配观察输入，右手捏合在空白处或模型上都可开始观察，不依赖模型拾取。平移按相机视平面及当前距离映射，环绕保持角度限制与目标点。
5. **两边联调。** 手势仓库负责识别与反馈，ViewForge 负责相机和原有物体事务，禁止复制 Three.js 场景逻辑或修改物体坐标来假装调整视角。
6. **验收与记录。** 更新说明、LOG 和配套版本。前端源码与构建产物同步；不因新增数字识别而重训模型或重建场景。

## 验证清单

- 数字：1/2/3、常见误姿态、过渡手型、右手不能选模式、左右标签翻转、双候选、遮挡、帧延迟；稳定确认只触发一次。
- 模式：按钮与数字输入一致；操作中/校验中不切换、不重放；idle 下切换成功后必须松手再抓取。
- 观察：平移与环绕分别符合已确认映射，模型与布局 JSON 不变，不调用 validate/save；仅观察时不误抓模型。
- 相机：释放首帧固定、丢手冻结、取消恢复、角度约束、惯性清理、高 DPI、窗口缩放及鼠标抢占。
- 物体回归：移动、自由旋转、承托叠放、碰撞拒绝、轻量→全量替换、取消和旧结果保护保持通过。
- 手势仓库执行 npm test、typecheck、check:resources、build；ViewForge 执行 check、test、build。合成自动化与真人手感记录分开。

当前仅首版代码已提交；本文件中的左手数字与观察扩展均未实现。
