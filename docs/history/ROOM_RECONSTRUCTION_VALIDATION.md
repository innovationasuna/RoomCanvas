# 房间安装与回放的历史验证

以下结果由原房间重建指南迁入，反映记录当时的环境与样本。本次文档重组只核对仓库源码，未重新安装环境或运行推理。[当前安装与运维](../SERVER_DEPLOYMENT.md)

| 日期或样本 | 验证及结果 | 边界 |
| --- | --- | --- |
| 2026-10-30 | 在 Ubuntu 26.04、RTX 4090、无 sudo 的服务器上从零安装，主环境、CUDA 12.4、Blender 通过检查。 | 当次未完成 TRELLIS.2 全新编译与模型下载的验证。 |
| 2026-11-03 | 在 RTX 3090 服务器的已有环境上运行 `scripts/setup_server.sh all`，各组件按已有目录执行检查，全部通过。 | 安装脚本不执行 GPU 推理。 |
| room3 回放样本 | 原记录中，`room_replay.py --slim-to` 将 55 GB 运行目录精简为 245 MB 的副本，回放内容一致。 | 单个样本的测量。精简副本只用于回看。 |
