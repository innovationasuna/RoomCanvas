# 物体重建加速实验结果

2026-11-18 在 `scut407` 的 GPU 1 上完成了五次蓝色保温杯重建，并用已有的保温杯和 Porsche GT3 网格做了对照。**最快的保温杯重建用时 119.96 秒**，采用 NVMe SSD 权重、MV 权重内存映射加载（`mmap`），并在展开 UV 前将导出网格简化到 10 万面。

## 五次完整重建

输入为同一组两张照片及掩码，采样步数为 50/25，随机种子为 42，贴图为 2048 × 2048。总耗时从重建脚本开始算到 COVER 完成。

| 运行 | 权重位置 | 配置 | 总耗时 |
| --- | --- | --- | ---: |
| `baseline01` | 机械盘 | 原始加载和导出 | 579.13 秒 |
| `baseline02` | 机械盘 | 原配置连续再跑一次 | 500.33 秒 |
| `mmap01` | 机械盘 | 启用 MV 权重内存映射，保留原网格导出 | 243.46 秒 |
| `combinedfast01` | 机械盘 | `--fast-export`，启用内存映射并将导出网格简化到 10 万面 | 410.56 秒 |
| `ssdfast01` | NVMe SSD | 同一 `--fast-export` 配置 | **119.96 秒** |

各次运行的系统缓存和服务器负载不同，固定随机种子也产生了略有差别的网格。各项优化的独立收益以分阶段对照为准。

## 加载、UV 和纹理烘焙

- **权重冷加载。** 分别从 `/home/data1` 的机械盘和 `/home/student2` 的 NVMe SSD 读取相同权重，首次测量前已确认大权重文件的缓存驻留量为零。DA3 从 83.84 秒降到 7.57 秒，MV 从 128.64 秒降到 11.87 秒，两者合计节省 **193.04 秒**。紧接着重复加载时，两块盘分别耗时 13.28 秒和 12.72 秒。
- **权重加载方式。** 独立进程中，MV 原方式两次测得 20.51 秒和 10.97 秒，内存映射为 5.69 秒，CPU 初始化加内存映射为 17.48 秒。各次加载后的模型状态指纹一致。此组实验按顺序运行，系统缓存未受控。
- **GPU 空闲的原因。** 两次基线重建的 UV 展开和保存约为 200 秒和 244 秒。在对应时间窗内，每秒采样得到的 GPU 利用率全部为 0%，CPU 平均使用约 3.1 个核心。首次 DA3 加载阶段另观察到了磁盘读取等待。
- **UV 分辨率。** 在同一份保温杯网格上，将 xatlas 图集分辨率从默认值改为 2048，耗时从 199.58 秒变为 199.16 秒。

下表每组都从该物体的同一份网格开始。保温杯使用同一份 Gaussian 重烘焙，以便比较贴图。

| 物体 | 导出面数 | 简化加 UV | 纹理烘焙 |
| --- | ---: | ---: | ---: |
| 保温杯 | 313,860（原网格） | 199.58 秒 | 25.36 秒 |
| 保温杯 | 100,000 | 13.75 秒 | 25.19 秒 |
| 保温杯 | 50,000 | 5.65 秒 | 25.06 秒 |
| GT3 | 547,392（原网格） | 91.24 秒 | 未重烘焙 |
| GT3 | 100,000 | 11.64 秒 | 未重烘焙 |

固定三视角检查中，保温杯的轮廓与贴图接近原版，GT3 的尾翼和轮毂基本保留。10 万面适合作为已验证的快速导出选项。5 万面仅在保温杯上试过，浏览器近距离外观尚待验证。

## 实际耗时与交互等待

最快一轮在第 **72.25 秒**生成原分辨率顶点色模型，第 **114.14 秒**生成带贴图的 10 万面 GLB。10 万面简化发生在最终导出前，基础模型沿用原网格。

如果在前端先导入基础模型，纹理就绪后原位替换，这个案例可以提前约 **42 秒**摆放物体。已测量的是两个文件的生成时间，前端原位替换仍是待实现的方案。此轮两阶段采样合计约 21 秒，纹理烘焙约 26 秒。模型常驻、减少采样步数、减少烘焙迭代均未做对照。
