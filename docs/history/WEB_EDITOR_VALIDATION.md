# 网页指南的体验耗时记录

重组前的网页指南给出以下两个耗时范围。原文没有记录具体硬件、输入版本、样本数或计时日志，保留在此供对照。本次文档整理未重新计时。

| 场景 | 原指南给出的量级 | 范围 |
| --- | --- | --- |
| 钢琴和琴凳等紧邻的高面数模型进行完整碰撞检查 | 约 1–2 秒 | 编辑器后台落点检查期间显示黄色「检查中」。 |
| 单张或多张物品照片经深度估计和三维重建生成模型 | 一般 3–8 分钟 | 物品任务可能排队。输入、GPU 和冷启动均会影响实际耗时。 |

可复现的编辑器采样方法见[编辑器测试与性能采样](../architecture/web-editor-internals.md#测试与性能采样)。有明确设备、运行条件的物品重建实测见[物品重建性能实验](OBJECT_RECONSTRUCTION_PERFORMANCE.md)。
