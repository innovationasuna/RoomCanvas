# 工程约定

- 仅修改本工程，保留平级工程。沟通、文档与日志使用中文。
- camera、tracking、gestures、controls、scene、ui 分层；鼠标与手势共用控制入口。
- 未经用户明确要求，不创建子 Agent、不提交、推送或部署。
- 摄像头必须由用户按钮开启；默认不录制、不上传、不持久化画面或关键点。
- 失效立即冻结，重获后松手再抓取；不能把失踪当作放置确认。
- 模型、WASM、依赖和资产来源、许可、版本与校验值记录在 docs/sources.md 和 public/vision/manifest.json。
- 修改后执行相关测试与构建，真实设备验收单独记录，不把合成测试当作真人达标。
- 每个完成阶段在本地开发记录 `docs/DEV_HISTORY.md`（不进仓库）的“手势模块开发日志”中追加记录。
