# RoomCanvas 手势接入

更新：2026-10-23。手势识别只驱动 RoomCanvas 编辑器，物体重建后端不参与摄像头、手势消息或场景操作。

## 推荐入口

在仓库根目录执行 `python3 web/scripts/serve.py`，打开 <http://127.0.0.1:7880/web/> 并选择房间，点击编辑器的“手势”按钮。摄像头默认关闭，视频和关键点只在本机浏览器 Worker 中处理，不录制、不上传。

识别代码由 `src/embed/index.ts` 打包到 `web/vendor/gesture/`，复用 `src/integration/runtime.ts` 和手势状态机。`web/editor/gesture-camera.mjs` 将帧直接交给 `gesture-bridge.mjs` 的 `GestureInput`。鼠标和手势共用编辑器的操作入口、承托与碰撞逻辑。

## 可选的独立识别页

在仓库根目录运行：

```bash
sh scripts/gesture.sh install
sh scripts/gesture.sh dev
```

打开 <http://127.0.0.1:8800/roomcanvas.html>。默认嵌入 <http://127.0.0.1:7880/web/editor/?room=room3>，地址栏或 `?layout=<编码后的编辑器 URL>` 可指定其他 RoomCanvas 房间。这个页面只显示摄像头和控制反馈，房间仍由 RoomCanvas 渲染，不需要 ViewForge 隧道。Vite 同时保留原独立识别演示 `index.html` 作为开发夹具。

iframe 协议为 `roomcanvas-gesture-v1`，双方校验本机 origin、source、会话和递增序号。仅发送镜像指针、捏合状态、模式和操作反馈，不发送视频、原始关键点或深度。已移除原 ViewForge 手势页及其场景接收端。

## 操作

| 控制 | 手势 | 结果 |
| --- | --- | --- |
| 移动 | 左手 1，右手捏住家具移动 | 沿平面移动，保持当前高度 |
| 高度 | 左手 2，右手捏住家具上下移动 | 抬高或放低；松手可悬空，切换 1 后继续平移 |
| 场景缩放 | 左手 3，松手后双手同时捏合拉开／靠近 | 改变相机 zoom，不改变家具尺寸 |
| 旋转 | 左手 4，右手捏住家具横移 | 连续旋转，一画面宽度 1080° |
| 环绕 | 左手捏合移动 | 独立环绕，右手可同时操作家具；不依赖右手入画 |
| 放置 | 松手后右手竖拇指，四指收拢，保持约 500ms | 确认当前预览，仍经过原碰撞、承托、落下及保存流程 |

数字保持约 400ms 后切换；操作中不切换，恢复后先张掌。数字 3 支持拇指与食指合拢、中指／无名指／小指伸出，也保留食指／中指／无名指伸出的手型；数字 4 需要拇指收拢，五指张掌用于重新准备。空闲时成圈的 3 优先用于选模式，避免被左手环绕抢占。

松手只保留预览，竖拇指、放置按钮或 Enter 才确认；轻捏不会确认，换拿另一件也不会替前一件自动保存。放置失败保留预览，可继续调整。一次连续竖拇指只确认一次，放下拇指后才能再次确认。

左右手分别冻结和重新准备：释放首帧不再移动，缺失 200ms 中断对应会话，恢复后先松手再抓取。丢手不能确认。双手缩放期间暂停环绕；正常结束后仍捏合的左手从新基准继续环绕，丢手结束则先松手重抓。相机环绕时重算右手抓取偏移，减少静止右手导致家具跳动。

两个入口均显示与镜像视频对齐的骨架。场景里右手琥珀色、左手青绿色，显示拇指／食指、连线和控制中点。两指距离达到掌部尺度的 0.8 倍时隐藏该手辅助标记，释放信号仍正常送达。隐藏、折叠、禁用的控件不会被手势选中，导出布局需要鼠标或键盘。

## 协议与兼容

协议仍为 `roomcanvas-gesture-v1`，通过 `dual-hand-v2`、`thumb-confirm-v1` 能力协商启用新行为。双手信号包含各自的捏合状态、中断状态和必要指尖显示坐标；原始视频与完整骨架不跨 iframe。

确认消息绑定当前 `previewId`、会话、递增序号和采样时间；超过 500ms、旧预览、正在抓取／缩放、页面隐藏或场景忙碌时拒绝，不排队补发。两入口共用 `confirmSession()`，不绕过碰撞检查。旧版观察消息仍可解析，原独立演示与识别资源保留。

相对主线的具体差异和提交边界见 [手势更新对照](gesture-updates.md)。

## 检查与构建

在 `gesture/` 运行 `npm run typecheck`、`npm test`、`npm run check:resources`、`npm run build`；内置识别包用 `npx vite build --config vite.embed.config.ts` 生成，并随源码更新。编辑器测试见 `web/README.md`。

自动化与合成输入检查不代替物理摄像头验收；手型准确率、左右方向和长时间性能仍需真人体验。模型版本、资源校验值与许可见 [来源](sources.md)。
