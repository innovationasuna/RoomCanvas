# 手势与操作说明

本页记录原独立演示 `index.html` 的规则。RoomCanvas 编辑器及 `roomcanvas.html` 的数字模式、双手控制和竖拇指确认见 [RoomCanvas 手势接入](roomcanvas-integration.md)。

固定右手操作物体，左手捏合环绕相机、张掌打开菜单、握拳关闭菜单，也参与双手缩放，不提供角色交换。摄像头必须点击开启。

主场景和摄像头预览均显示两手拇指/食指指尖、连接线和中点：右手半透明天蓝色，左手半透明浅绿色；捏合时对应中点圆环加深。指尖对随各自平滑中点整体平移，保持连线中点和控制位置一致。相应手丢失时隐藏该手标记，停止摄像头隐藏全部；叠加层不拦截鼠标或菜单。只有右手中点能选择菜单项。

| 操作 | 模式/手势 | 结果 |
| --- | --- | --- |
| 打开菜单 | 未抓取时辅助手张掌保持 600ms | 打开固定屏幕菜单，场景停止响应 |
| 握拳关闭菜单 | 左手四指收拢保持 200ms | 关闭当前菜单（含复位确认），不执行选项；先松手再操作场景 |
| 选择/关闭菜单 | 操作手指向选项再捏合 | 确认后先松手，再操作场景 |
| 指向 | 拇指/食指中点移动 | 家具高亮 |
| 移动家具 | 移动模式，指向后捏合保持 | 沿地板 XZ 移动，保持抓取偏移 |
| 放置 | 松开捏合并确认 40ms | 提交，加入撤销历史 |
| 家具旋转 | 旋转模式，右手捏合后水平移动 | 绕 Y 轴；一画面宽度对应 180°，15°吸附 |
| 高度 | 高度模式，捏合后上下移动 | 一画面高度对应 3m，限制地板到天花板 |
| 场景旋转/环绕 | 任意模式，左手两指捏合拖动 | 左右水平环绕、上下俯仰；松开固定，不需要命中家具，右手可不入画 |
| 观察（兼容入口） | 观察模式，右手捏合拖动 | 相机环绕；距离 3.5–14m |
| 观察距离 | 观察模式，双手捏合拉开/靠近 | 拉开放大视角（相机拉近），靠近拉远 |
| XYZ 自然深度 | 移动模式，单手捏合后前后移动 | 投影尺度变大向观察者靠近，变小进入深处 |
| 模型缩放 | 仅 XYZ 缩放模式，双手捏合拉开/靠近 | 相对间距比，0.5–2 倍 |
| 撤销 | 菜单选“撤销” | 撤销当前场景最近操作；优先撤销中断预览 |
| 复位 | 菜单选“复位”，再选确认 | 当前场景物体与视角复位，XYZ 任务计数重置 |
| 切换场景 | 菜单选室内/XYZ | 各场景物体状态和历史独立保留 |
| 暂停/恢复 | 菜单对应选项 | 暂停仅保留菜单手势响应 |

## 连续控制规则

捏合比值进入阈值 0.25，退出阈值 0.30；抓取确认 100ms，释放独立确认 40ms，左右手一致。One Euro Filter 根据时间戳平滑指针和尺度。当前为根据用户手感反馈调整的试用参数，不能视为准确率已经验收。

## 调整松手手感

修改 src/shared/config.ts，保存后开发页面会重新加载，需要重新开启摄像头。生产预览需重新构建。

| 参数 | 当前值 | 调整方向 |
| --- | --- | --- |
| pinchExit | 0.30 | 越低，手指分开越小距离就能触发释放；始终大于 pinchEnter |
| releaseConfirmMs | 40 | 越短，释放确认越快；过短更容易把短暂抖动当作松开 |
| pinchEnter | 0.25 | 越高越容易触发抓取；本次保持原值 |
| confirmMs | 100 | 抓取确认时间；本次保持原值 |

先试当前值。仍需更快释放可单独试 releaseConfirmMs=20；若主要是必须张开太大，可单独试 pinchExit=0.28。一次只改一项并检查误释放。40ms 是收到识别帧后的连续确认要求，不是端到端延迟保证；实际还受推理频率影响。右手放置、左手停止环绕和双手操作结束共用这组参数，追踪失效规则保持独立。

普通手部移动不触发物体变换。右手物体候选必须明确标为 Right，左手视角候选必须明确标为 Left，左右手分类分数均至少 0.8；位置连续性只能进一步拒绝候选，不能覆盖手的角色。标签翻转、分类不确定、同一角色多个候选或近距离重叠时冻结该手控制，不互相接管。

左手环绕不依赖右手是否入画。每次左手捏合建立当前视角基准，一画面宽度约对应水平 360°，一画面高度约对应俯仰 180°，实际俯仰受相机上/下限约束；松手结束，不增加物体撤销记录。

右手物体抓取和左手视角拖动可以同时进行，先开始哪只手均可。松开左手只结束视角拖动，右手可继续操作；松开右手提交物体操作，左手可继续环绕。视角变化后家具移动在最后有效右手位置重建地板交点基准，XYZ 移动重建相机坐标轴与相对基准，避免静止右手把物体拖走。单手追踪中断只冻结并中断对应会话，恢复后该手需松手重新抓取。观察模式或 XYZ 缩放模式中，两手同时捏合优先双手缩放；结束后两手先松开，不自动退回单手环绕。菜单打开、暂停或整体追踪中断会停止两手控制。

失踪立即冻结；200ms 中断会话，必须重获、松手、重新抓取。保留最后有效位置，不将失踪当作放置确认。

XYZ 是相对深度而非距离测量。转掌提示出现时只更新平面位移；请面向摄像头，重新建立尺度参考。视觉上提供目标距离、停留进度、光标地面投影和相机纵深标尺。

## 鼠标备用

场景左键拖动执行当前模式；菜单/模式按钮可点击。XYZ 移动模式滚轮控制深度，缩放模式滚轮控制光标大小；其他模式滚轮控制相机距离。鼠标拖动时暂停手势变换，结束后手势必须松手重抓。Esc 关闭菜单并中断当前操作。

复位的撤销只恢复物体变换，不恢复相机或已经重置的 XYZ 测试计数。

## 场景指尖显示距离

`src/shared/config.ts` 中 `fingerGuideMaxRatio` 当前为 **0.8**。以指尖距离除以掌部尺度计算，达到或超过上限时隐藏该手的场景指尖点、连线和中点，低于上限重新显示。左右手独立判断，右手天蓝色、左手浅绿色保持不变。调小上限会更早隐藏，调大会允许两指分得更开。这个参数只影响场景反馈，不改变捏合阈值、菜单命中或摄像头预览骨架。

菜单关闭确认时间在 `src/shared/config.ts` 的 `menuCloseHoldMs` 调整，当前 200ms。只有可信左手的四根手指同时收拢才触发，普通两指捏合不会关闭菜单；出画会取消尚未完成的确认。握拳在菜单关闭时不执行额外命令。

## 松手防漂移

捏合状态下，两指距离达到 `pinchExit` 的第一帧就冻结该手的控制中点和掌部尺度，不把张开时的上移送入位置滤波器；保持 `releaseConfirmMs` 后才确认结束。物体操作提交最后稳定变换，视角保持最后稳定角度。短暂张开未完成确认又捏合时可恢复控制。右手与左手独立冻结，另一只手可继续；双手缩放在任一手开始释放时冻结缩放，确认后结束。指尖显示仍遵守显示距离上限。
