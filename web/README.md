# 网页编辑器与重建回放

<a id="网页编辑器"></a>

在首页选一个房间，打开「布置」，就可以按真实尺寸移动物品、比较光照或保存布局。「体验」可以开合门窗、走进房间。要在手机上看同一份布置，从编辑器右上角分享。

## 启动

本机需要 Git 和 Python 3。第一次使用时，在准备存放项目的目录执行以下命令。已有仓库可直接在根目录执行最后一行。

```bash
git clone https://github.com/innovationasuna/RoomCanvas.git
cd RoomCanvas
python3 web/scripts/serve.py
```

打开 <http://127.0.0.1:7880/web/>。已下载的示例、已缓存的房间和回放可以离线打开。要上传扫描、拍照生成物品或导入服务器已有的物品，请连接相应服务。

已有服务器时，先用 SSH 确认能登录，退出后在本机仓库根目录执行下面的启动命令。把主机名换成自己的 SSH 别名或登录目标。

```bash
python3 web/scripts/serve.py --ssh '<SSH 主机>'
```

默认只建一条转发，本机 7865 连接远端网关 7870。按 Ctrl-C 会一起关闭网页服务和转发。容器、独立服务及已有隧道的配置见[从电脑连接](../docs/SERVER_DEPLOYMENT.md#从电脑连接)。

### 示例房间的模型

启动后会后台下载缺少的模型。打开房间时若提示缺模型，可登录有仓库读取权限的 GitHub 账号，再按终端给出的路径获取并刷新。只取办公室可运行以下命令。

```bash
python3 scripts/fetch_samples.py office
```

示例模型也可从已连接的房间服务按需取得。[下载、校验与缓存](../docs/SERVER_DEPLOYMENT.md#示例模型与本机缓存) · [新增或更新示例模型](../docs/architecture/web-editor-internals.md#示例模型的读取与发布)

### 共享服务器的服务凭证

通过 SSH 启动时，网页服务会自动读取凭证。浏览器可直接使用。自建隧道或更改凭证位置时，见[服务凭证](../docs/SERVER_DEPLOYMENT.md#服务凭证)。

## 界面

| 想做什么 | 操作 |
| --- | --- |
| 看尺寸和位置 | 单击物品。绿色高亮表示选中，详情显示宽、深、高，以及相对初始位置的水平、高度和旋转变化。 |
| 移动、旋转或抬高 | 拖动已选物品超过 5 像素，或使用详情中的移动摇杆、旋转转盘和升降拉杆。拉杆离中心越远，升降越快。壁挂物可沿墙移动、换墙。 |
| 完成调整 | 松手保留预览，确认后才放置，也可取消。绿色表示可以放置，红色表示受阻。黄色「检查中」时可以先点确认，检查通过后会放下。 |
| 看全屋或单件物品 | 「整体」和双击物品聚焦使用透视视角，「俯视」使用正交视角，适合对照尺寸。 |
| 移动镜头 | 右键拖动平移，滚轮缩放。按住 Shift，用左键或触控板单指按住并拖动空白处、未选中的物品，即可旋转视角。中键按下无编辑操作。 |
| 收纳或放回 | 左侧「物品库」默认收起。展开后可按「房间中／已收纳」筛选，卡片显示缩略图和尺寸。按 `/` 打开并搜索，用关闭按钮或 Esc 收起。 |
| 保存、恢复与撤销 | 房间名菜单可导入、导出布局 JSON，或选择「继续上次布置」。每次打开先显示原始布置。「收起全部物品」与「恢复原始布置」都可以撤销、重做。 |
| 调整工具 | 左侧「设置」可选简洁／完整、开关提示或重看引导。工具模式和提示偏好保存在当前浏览器。简洁模式选中后收起物品库，完整模式在宽屏可并排看物品库和详情。 |
| 对照比例 | 「环境」可开关地面网格。大格 1 米，小格 25 厘米，红绿轴沿房间主墙方向。拉远后过渡到 10 米参考线，漫游时自动隐藏。 |

左侧面板一次展开一个，开合时镜头和画布保持原位。上手引导随选择和调整给出下一步，保存提示会说明是否已写入当前浏览器。

**保存范围。** 布局记录房间原有物品。后来添加的物品可以随完整房间快照分享。刷新编辑器后，需要从「从已生成的模型添加」重新加入。

## 近侧墙

完整工具模式下，在「环境 → 近侧墙」选择实心、半透明或隐藏（默认）。靠近镜头的墙会连同门窗、插座、窗帘和挂画一起处理，高柜及其托住的物品也会避开视线。

鼠标和手势都可以穿过隐藏或变淡的物品。正在摆放的物品始终实心。切换显示方式不会改变碰撞和支撑。

## 光照

在左侧「环境」选择光照，切换「室内灯」比较开灯和关灯的效果。灯光跟随房间已有的顶灯。缺少灯具时会自动补光。

| 选项 | 能看到什么 |
| --- | --- |
| 普通光照 | 中性照明，方便比较不同物品的颜色。 |
| 早晨 | 主窗一侧有低角度的金色阳光，天光、窗景和背景偏冷，较中午稍暗。 |
| 中午（默认） | 阳光更高、接近中性，窗边最亮，顶灯微亮。 |
| 下午 | 阳光从主窗另一侧斜照，光斑偏琥珀色，影子更长，窗景稍暗。 |
| 夜间 | 顶灯照向桌面和墙面，墙顶有柔和反光。室外呈深蓝色，主窗可映出室内。关灯可直接比较。 |
| 物理光照（实验） | 用接近 Android 漫游的照明方式看房间，可与其他时段比较顶灯和窗光。 |
| 室内灯 | 完整工具可调聚光灯照射角度，默认 160°，可选 60°–170°。角度和开关都按房间保存。 |

完整工具里的「画面调色」可改曝光、冷暖、对比度和饱和度。切换时段时保留调色，刷新后恢复默认。「导入物品随光照变化」可用来比较旧模型。新生成的 PBR 模型会直接受光。

## 开合部件

切到「体验」，点门、柜门、抽屉或窗即可开合。可操作部件会显示手形和动作提示。升降桌上的物品会随桌面升起，钢琴盖上的谱子也会随盖板转动。

视线被窗帘或近侧墙挡住时，转动镜头再试。回到「布置」会关闭部件，按关闭姿态检查摆放。若有待确认的调整，请先确认或取消。

## 漫游

在「体验」点「走进房间」。初始视线高 1.6 米，碰到墙和物品会停下。

| 操作 | 效果 |
| --- | --- |
| Shift＋左键拖动，或在触屏上拖动 | 转头 |
| W、A、S、D 或方向键 | 行走，按住 Shift 快走 |
| Q／E | 升高／降低视线，范围为离地 0.5–2.2 米 |
| 点门窗、柜门或抽屉 | 开合部件 |
| Esc 或「退出漫游」 | 回到进入漫游前的模式 |

## 添加与导入物品

1. 在物品库点「添加物品」，命名并选 1–40 张 JPEG、PNG、HEIC 或 HEIF 照片。可以只用一张，建议围绕物品多拍几个角度。
2. 等照片预览就绪再上传。绿色区域是识别出的物品，点选不合适的照片以排除，至少留一张。
3. 确认后等待重建。忙时会排队，关闭弹窗或刷新后仍能从卡片查看进度。若物品服务重启，可在「从已生成的模型添加」查找已保存的结果。
4. 选择一条实际量过的边并输入长度。红 X 为宽、绿 Y 为深、蓝 Z 为高。点箭头标签可换方向。转动视角时，标签会跟随。确认后模型出现在靠近房间中心的空地上。

**补拍。** 橙色箭头指出推荐方向，点「看推荐角度」可转到该视角。「补拍」保留原照片和抠图，只给新照片抠图，再结合原有和新增角度重新建模，另存一份新结果。已有结果或没有推荐方向的旧模型也可补拍。

**导入已有模型。** 「从已生成的模型添加」会读出服务器保存过的尺寸。缺少时补填一条实测边长。卡片右上角的删除按钮仅移除当前房间里的这份实例。原有物品可收纳。[物品重建操作与结果](../docs/OBJECT_RECONSTRUCTION.md)

## 物品库与手势

在左侧「手势」面板点「开启手势与摄像头」。画面会显示镜像骨架和左右手状态，房间内有指尖、连线和中点。收起面板后侧栏圆点表示识别仍在运行。要停用，请在面板关闭摄像头。

- 左手比 1、2、3、4，分别切换平移、抬高、场景缩放和旋转。左手捏合环绕视角，双手捏合拉开或靠近可缩放场景。
- 右手捏住物品或物品库卡片调整，松手后保留预览。竖拇指约 0.5 秒、点放置按钮或按 Enter 确认，拇指向下取消。确认时会检查碰撞和是否能落下。
- 跟踪丢失时操作暂停，手重新进入画面后先松手再抓取。布局导出请用鼠标或键盘。小窗口下优先用编辑器内置手势。[手势操作与摄像头](../gesture/docs/roomcanvas-integration.md)

## 重建房间

在首页点「重建房间」，上传一个房间的完整扫描包（ZIP／TAR／TAR.GZ／TGZ）。页面标注上限为 2 GB。关闭网页后服务器仍会继续。出现「重试」时可继续。若提示扫描包损坏，请重新上传完整包。[扫描包要求与提交步骤](../docs/ROOM_RECONSTRUCTION.md#从网页重建房间)

首页右上角的「重建记录」列出全部已开始的重建任务。排队和运行中的房间也有首页卡片。点「实时查看」可看当前阶段，点「查看过程」可回放。左侧是分阶段的图文，右侧从扫描点云、物品框变成房间模型，底部时间轴可拖动。完成后点「进入布置」。[回放操作](../docs/ROOM_RECONSTRUCTION.md#查看重建过程)

卡片「… → 删除房间」经确认后会把房间和任务入口移入本机回收站。运行中的任务会继续，扫描和模型文件保留。首页右下角可看已删除数量，点开可逐个恢复。刷新或重启仍保留此状态。

## 清理本地缓存

首页右下角「本地缓存」按房间显示模型、回放文件数和占用，可选中几项或清理全部。示例及其对应回放会合并显示。预计释放空间按实际占用计算，共用的数据只计一次。

清理影响本机下载副本。原始扫描、服务器结果、房间清单与缩略图、浏览器布局和回收站会保留。清理「离线房间列表」后，离线时可能暂时看不到服务器房间。

提示正在读写时，等操作结束再试。清理后会暂停后台预下载，重启仍有效。打开单个示例仍可按需下载。在线时也可直接读取其他房间与回放。[缓存命令与恢复预下载](../docs/SERVER_DEPLOYMENT.md#示例模型与本机缓存)

## 在手机中打开

点编辑器右上角「在手机中打开」，可导出当前房间模型或生成二维码。同一 Wi-Fi 下，手机扫码可直接触摸漫游。Android 安装 RoomCanvas 0.2.0 或更新版后也可从分享页导入，下载成功后可离线重开。[手机体验与 App 导入](../docs/MOBILE_HANDOFF.md)

## 房间文件

| 文件 | 用途 |
| --- | --- |
| 房间目录中的 `Room.glb` | 编辑器加载的房间模型。 |
| 同目录的 `room_objects.json` | 区分结构、固定设施、可搬动物品、支撑面及可开合部件。 |
| 同目录的 `thumbnail.jpg` | 首页封面，通过整体视角截图生成。 |
| [房间列表](rooms.json) | 手动添加房间时填写编号、名字、目录和介绍。服务发布的房间自动加入首页。 |

可用 `editor/?room=office` 直接打开办公室。任意目录接入、清单生成、缩略图和独立发布见[房间目录与清单](../docs/architecture/web-editor-internals.md#房间目录与清单)。
