# ViewForge 早期独立界面

这里保存早期的 Gradio / Babylon 独立界面，当前服务不加载本目录。使用入口是 [网页编辑器](../../web/README.md)，部署见 [物体重建](../../docs/OBJECT_RECONSTRUCTION.md)。

| 目录 | 内容 |
| --- | --- |
| `scripts/` | Gradio 页面、会话与布局逻辑，`assets/` 保存页面资源和查看器构建产物 |
| `viewer/` | Babylon 单物体与房间查看器源码、构建工具和依赖锁文件 |
| `gesture/` | 独立界面的手势接入页 |
| `configs/` | 房间布局依赖配置 |
| `tests/` | 独立界面与会话测试 |

`requirements.txt` 记录独立界面依赖；许可证文件随代码保留。
