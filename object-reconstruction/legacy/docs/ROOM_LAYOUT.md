# 房间布局（GLB）

主网页顶部“打开房间布局”进入独立页面。房间数据默认读取
`$VIEWFORGE_ROOT/../RoomCanvas-Reconstruction/runs`，可用 `VIEWFORGE_ROOMS_ROOT` 覆盖。
目前注册 RoomPlan 办公室、茶室及扫描配准后的照片办公室；不将未经尺度校准的原始照片重建当作米制。

安装 CPU 碰撞依赖：`python -m pip install -r configs/layout-requirements.txt`。
前端修改后在 `viewer/` 执行 `npm run check && npm run build`。后端修改需重启网页服务。

## 操作

1. 预览房间，选择参考墙（橙色），按需输入实测墙长，确认并固定房间比例。
2. 选择已有物体、读取尺寸。已有单轴标定会自动填入；也可输入新的方向与实际米数，此操作只标定新布局实例。
3. 点击地面设置位置，再加入物体；初始手动缩放为 1。物体底部中心默认贴地，可以调整离地高度进入较高的凹槽。
4. 选中物体，修改地面 X/Y、离地高度、竖直轴旋转和等比例缩放，应用后通过服务端碰撞检查才生效。恢复标定大小会重新检查碰撞。
5. 保存生成一个不可覆盖的布局快照；重新打开保留房间、物体标定、位置、旋转和手动缩放。

显示坐标延续 X=内部 X、Y=内部 -Z、Z=内部 Y；GLB 及计算仍使用右手 Y-up。
渲染矩阵为 `平移到地板与位置 × 绕竖直轴旋转 × 标定比例 × 实例缩放 × 底部中心归零 × 原模型显示变换`。
碰撞使用完全相同的变换和完整 GLB，绝不以轻量 GLB 的包围盒作为物体间阻挡依据。
轻量模型显示后继续加载全量，保持同一父变换；失败保留轻量版本。

## 碰撞与限制

- FCL BVH 三角网格检测物体/物体、物体/真实墙体，保留桌底和凹槽。
- 对封闭连通分量追加内部包含检测，拦截无表面交叉的完整嵌入。
- 地板轮廓检查全部物体顶点；墙体网格拦截跨越凹形房间边界的表面，层高阻止穿顶。
- 未封闭网格可做表面相交检测，但内部包含仅覆盖封闭分量，界面显示限制。重建误差也直接影响碰撞结果。
- 检查最终摆放位置，不模拟搬运路径或物理落体；默认贴地，手动离地摆放不做重力或支撑稳定性计算。网格接触也按碰撞处理，紧贴表面需留微小间隙。
- 房间源文件指纹和物体源版本变动会拒绝旧布局，避免静默改变基准尺寸。
- 当前每次操作由服务端检查，首次构建完整网格 BVH 可能较慢，后续缓存；不是每帧物理模拟。缓存受数量限制并由锁保护。

布局保存在 `$VIEWFORGE_ROOT/data/layouts/<uuid>.json`，不修改源 GLB 或原物体的 `dimensions.json`。
API：`/viewforge/layouts/catalog`、`assets/<run>`、`rooms/<id>.glb`、`validate`、`save`、`<uuid>`。
模型只有固定目录白名单可读；写入接口同源校验、重新测量原模型并执行碰撞校验。

测试：`python -m unittest discover -s tests -p test_layouts.py -v`。

## 鼠标摆放

画面左上可选“移动物体 / 旋转物体 / 仅观察房间”。默认直接拖动物体沿地面移动，保持原离地高度和尺寸；选中后拖动蓝色圆环绕竖直轴旋转。“旋转物体”模式也可在物体上左右拖动旋转。Esc 或指针取消恢复原位。拖动空白处仍可观察房间。

拖动阶段只更新视觉预览，松开后自动用服务端完整网格校验；成功才修改布局，失败恢复拖动前的位置。校验期间禁止重复编辑，避免并发结果覆盖。原有数值标定、缩放、保存方式保持不变。

## 独立标定与布局联动

独立物体预览默认选择向上的 Z 轴，输入实际长度后“应用并保存”；也可以选择 X/Y。
布局页选取物体、返回页面或收到同源标定保存通知时自动读取最新标定。加入前再次读取，使用新的标定作为实例快照。
已放置实例不会随源物体之后的标定变动而改变。布局页手工填写的未保存输入在服务器标定未变化时保留。
“放置与缩放”默认仅显示实例选择和删除，精确坐标、离地高度、旋转与缩放位于默认关闭的折叠区内。

## 自动叠放与精简面板

房间标定、物体预览/标定和精确摆放参数均默认折叠。独立预览首次显示以米为单位；仍可手动切换 mm/cm。
鼠标默认“仅观察房间”。移动模型需切换“移动物体”，旋转使用鼠标自由调节角度。

初次导入：确认房间 → 选择物体并完成标定 → 点击“选择放置位置” → 点击沙发等物体表面或地面 → “加入场景”。
已有物体：打开“自动放到地面或物体表面”，拖动物体到另一物体上方，松开后自动求承托高度；拖到地板会落回地面。
关闭自动承托可保持原离地高度，继续手动设置精确数值。

高度计算使用完整 GLB 的实际三角面（不是整个沙发包围盒的最高处），经完整碰撞校验后才生效。表面查询索引缓存复用；最终保留约 2 毫米间隙以避免接触误判。若被墙体、其他模型或层高阻挡，回退原位置。
这是位置编辑功能：不模拟重力、软垫变形或抗倾覆稳定性，也不建立父子跟随关系；移动承托物体不会自动搬动上方物体。

轻量模型一旦显示即可操作，全量模型后台加载并自动替换，不显示后台加载或完成提示；后台加载失败时继续保留可用模型。仅在物体尚未显示或完全加载失败时提示用户。
